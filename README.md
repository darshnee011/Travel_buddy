# Travel Buddy Finder

## Project Description

Travel Buddy Finder is a full stack web application
that allows travelers to register their travel details
and view other registered travelers.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

1. Traveler registration
2. Destination entry
3. Travel date selection
4. Store traveler details in MongoDB
5. View registered travelers

## Installation

1. Clone the repository.
2. Run npm install.
3. Create a .env file.
4. Add the MongoDB connection URL.
5. Run npm start.
